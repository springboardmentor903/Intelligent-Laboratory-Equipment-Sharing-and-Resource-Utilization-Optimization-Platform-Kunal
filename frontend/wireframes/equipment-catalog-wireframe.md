# Equipment Catalog Wireframe
## Lab Resource Utilization Platform

### Header
- Platform logo and name
- Notifications
- User profile menu

### Sidebar
- Dashboard
- Equipment Catalog
- My Bookings
- Maintenance
- Notifications
- Profile

### Search and Filters
- Search equipment by name
- Filter by category
- Filter by availability
- Filter by laboratory or department, where applicable

### Equipment Cards
- Equipment image
- Equipment name
- Category
- Laboratory location
- Availability status
- View Details button
- Book Equipment button, when authorized

### Equipment Details
- Equipment name and image
- Description and specifications
- Laboratory location
- Availability information
- Maintenance and calibration information, where available
- Booking action, according to permissions

### Responsive Layout
- Desktop: 3-column equipment grid
- Tablet: 2-column equipment grid
- Mobile: 1-column equipment grid

### States
- Loading indicator
- No equipment found
- API error message
- Booking action success or failure
