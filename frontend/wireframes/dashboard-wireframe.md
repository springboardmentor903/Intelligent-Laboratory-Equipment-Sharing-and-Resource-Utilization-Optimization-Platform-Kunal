# Dashboard Wireframe
## Lab Resource Utilization Platform

### Top Navigation
- Platform logo and name
- Notifications icon
- User profile menu
- Logout option

### Sidebar
- Dashboard
- Equipment Catalog
- My Bookings
- Maintenance
- Notifications
- Profile
- Reports, where authorized

### Summary Cards
- Total Equipment
- Available Equipment
- Active Bookings
- Pending Bookings
- Maintenance Requests

### Main Dashboard
- Resource Utilization Chart
- Recent Bookings Table
- Equipment Availability Overview
- Recent Notifications and Activity

### Responsive Layout
- Desktop: Sidebar and main content side by side
- Tablet: Compact sidebar and responsive cards
- Mobile: Collapsible navigation and stacked cards

### Role-Based Content
- Show pages and actions according to the user's role.
- Enforce permissions through backend APIs.
