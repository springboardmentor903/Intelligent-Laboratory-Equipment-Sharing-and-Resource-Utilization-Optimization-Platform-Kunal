# Booking Calendar Wireframe
## Lab Resource Utilization Platform

### Header
- Page title: Booking Calendar
- Current month and year
- Previous and Next month controls
- Equipment selection

### Calendar
- Monthly calendar view
- Available time slots
- Booked time slots
- Unavailable time slots
- Selected equipment details

### Booking Form
- Equipment selection
- Booking date
- Start time
- End time
- Booking purpose
- Submit Booking button

### Booking Status
- Pending
- Approved
- Rejected
- Cancelled

### User Actions
- View My Bookings
- View booking details
- Cancel booking when permitted
- View booking status
- Display validation errors and booking conflict messages

### Responsive Layout
- Desktop: Full monthly calendar
- Tablet: Compact calendar
- Mobile: Calendar and booking form stacked vertically

### States
- Loading availability
- No available time slots
- Booking conflict
- Booking submitted successfully
- API error message

### Permissions
- Show booking actions according to role and policy.
- Enforce booking permissions through the backend API.
